# 视频参考图制作

适用：人物身份、场次定妆、场景、道具、镜头初态和首尾状态图，以及现有参考图返修。2026-10-06整理。采用可复用的图像方法；新图和视频效果仍须实际验收。来源与未采纳规则见 [研究来源](reference-image-sources.md)。

## 执行边界

图片路线遵循用户的工具、型号、尺寸与预算要求。型号未披露时如实记录，不把提示词中的型号当作实际路由；改变提供方或产生费用时遵循用户授权。

按需读取已安装imagegen说明。先看本地输入图，再按本会话真实工具参数绑定参考；所有目标有本地路径时使用工具支持的路径机制，否则只使用能包含全部目标的最近图片机制，二者不混。缺图如实补齐，不编文件、图号或素材标签。API文档的model、quality、size、input_fidelity、mask、seed或参考权重不自动成为内置工具参数。

已有合格图直接复用。内置工具生成结果不是项目稳定资产，选用图需复制到实际项目，保留原件并另存编辑版本。不默认内置工具免费、无限额度或固定原生4K；记录实际返回尺寸和可核对用量，未披露费用标为未知。

## 从镜头需要选资产

不是每位角色、每个镜头都要生成整套图。先找现有认可资产，只补该镜头缺的条件：

- 身份近景：说明是谁，脸、发际线、发型与识别配饰清楚，独立单人、自然表情、均匀照明。避免将重磨皮、遮脸逆光或强烈表演作为唯一身份源。
- 场次定妆：说明衣服、身体比例和配饰；半身或全身按镜头需要选，关键鞋/手/衣料可见。身份近景仍保留，不让全身小脸替代它。
- 场景基准：说明空间、门窗、桌椅、光源与通道。只需场景时优先无额外人物的底图，避免把其中陌生人也带入生成。
- 镜头初态：单幅实际构图，谁已在场、视线、手、道具、摄影机与动作尚未发生的状态。它应直接适合本镜，不能仅是一张好看的宣传照。
- 道具细节：只补容易误认、关键接触或需要近景的物件，核形状、材质、朝向及与手/桌面的关系。
- 终态：仅在需要收束或入口支持首尾时准备；与初态的身份、轴线、场景几何和画幅一致。跨地点/时代不靠首尾插值代替剪辑。

身份图不强制横屏；实际场景/初态遵循目标镜头画幅。人物总览、故事卡与多格拼图可供人工规划，不默认当单幅首帧。Seedance 2.0官方身份漂移排查推荐独立单人照，多视图拼图可能被当成多主体；多角度可分别准备并明确绑定同一人。这是该模型相关建议，其他入口按真实表现判断。

## 绑定来源、保留项与允许变化

查看每张输入，简短记录可观察的身份/数量/服装/姿态/光线和实际用途。原图不可见的特征不编造，导演设计与原图事实分开。优先级是用户最新明确要求与认可身份源，再按职责使用其他参考；旧合影被否定脸后仅保留空间用途。

在已有项目记录中为资产保留：source_id、文件路径、职责、保留项、允许变化、来源/派生关系、hash与验收状态。区分“用户认可身份”与“agent检查可用”，不能代用户宣布艺术验收。不为格式另建重复数据库。跨镜复用与更新时按 [制作记录](production-records.md) 保留身份根和派生时指纹；上游身份、风格或服装变化先复核受影响分支，不自动重生整套资产。

多图自然语言绑定示例：

```text
图1只控制主角的真实身份与发型；图2只控制本场外套的结构和颜色；
图3控制院子几何和机位，不复制其中的人物；图4只控制人物站位与视线。
输出保持图1中的同一个人，按指定衣服和布局进入图3场景。
```

使用上传后实际标签。场景图不能覆盖身份，风格图不能更改人数/衣服，布局草图不能变成最终画风。发生冲突先排除：不同人是否误称同一人、两种互斥服装、初态杯已举起却要求仍在桌上、人物朝向与视线相反。

## 保持同一个人，减少每次需要发明的内容

优先选择同一认可身份中与本镜最接近的机位、朝向、姿态和表情参考。侧面镜头不只给正面并要求大幅转身；有清楚侧面就优先使用，必要时再准备。没有多视角时以现有认可图为锚，不为“完整资料”强行批量生图。

身份是稳定的五官比例、脸型、发际线等；衣服、表情、年龄状态与场景分别管理。只换衣服不重写一长串泛化五官，让模型使用原图中的人。配饰与左右不对称特征明确身体侧和当前画面侧，换角度后核实际位置，避免镜像错误。

生成图可以成为后续编辑底图，但不能成为未经复核的新身份源。每次与原始认可身份源对照；有漂移就回到源图修复，不沿错误版本继续派生。只修目标问题，重复当前仍必须保持的身份、机位、姿态、人数及物件。

当身份在单人图中正确、一进入复杂场景就崩坏时，按需求拆成“同人定妆/目标姿态”与“加入已锁场景”两步；两步遵循同一已授权GPT图片路线，单步能完成则不强制拆分。分步方法仍可能产生漂移，逐步验收再继续，不用步骤数量当效果保证。

## 让构图、光线与材质能被执行

为每张镜头图明确一个主要信息：景别、摄影机高度/角度、人物占比、视线目标、焦点、前中后层次与所需运动余量。焦距/光圈词只是外观线索，不宣称模型精确模拟真实相机。

按叙事设计可见机制：孤独可用小人物与空旷空间，亲近可用平视与近距离，紧张可用受限动线与硬侧光。身份源保持可辨识，情绪与电影光影主要放在镜头图里；不能为强逆光或雾气隐藏本镜必须辨认的脸。

光线写主光来源、方向、软硬与填充，材质写织物、皮肤、玻璃等真实可见响应。夜景保留主脸暗部细节与必要手/道具；多人交互需要的角色和道具在景深范围内，不默认极浅景深。既有同场景主光、家具与机位关系跨镜保持，时代/天气变化仍服从剧情，不强行全片一个色温。

人物加入实景或场景母图时，同时核对同距离主体的曝光、局部对比、光向、边缘软硬和景深。检查鞋底与地面、手与衣料、身体相靠处的遮挡和接触阴影，以及花枝/前景物自然遮住下半身的关系。换衣服、鞋跟或裙长后重核有效身高、重心和接近姿态，再修受影响的双人场景图。

站位/视线反复失败时，可把简明布局或已有标注图作为仅控制空间的辅助参考，少量位置与视线信息配合文字。先生成并检查符合已选画风、无标注的最终单幅图，再送视频；箭头、角色标签与格线不能意外进入成片。外部平台的框选强度、角色库与权重不假设内置GPT支持。

## 镜头初态与多人场景

静态图呈现一个瞬间。准备碰杯应是杯尚未接触，准备进门应是门口或起步状态；不要一张图同时要求开始、过程和结束。终态另存，画幅与空间一致。

逐人绑定身份、服装、相对站位及是否已经入画；区分场内总人数和本镜可见人数。群体远景控制数量与布局，主角近脸参考提供身份，不能用大合影单独支撑所有角色的表情特写。

复杂入场按已经在场的阶段设计状态，最终人数只约束结尾，不规定全段人数恒定。增加新成员时逐步核新脸与已有角色；移位后原位置应空出，不保留原人再加副本。不能为了降低错误率删掉必须出场的角色。

检查手的归属、抓握/拍肩/递物的接触点、杯具数量与材质、人体比例和相互遮挡。需要展示的动作部位留在画内，不能靠裁掉错误手掩盖核心动作。尚未揭示的物件不提前入画；拍照设备在开始或结束可见与否按剧本判断，不套用统一禁相机规则。

## 清晰度、画幅与传输

依据任务设定目标尺寸与画幅，并以实际返回像素和主体细节验收。预览与正式交付分开；不能将插值放大标为原生高分辨率。复合三视图逐格检查结构与有效细节。

清晰度分开看：实际宽高、关键主体占比、面部/手/道具可辨细节、压缩与生成痕迹、最终视频输出。大像素、PNG或大文件不自动证明清晰；锐化/放大不能恢复准确身份或修复错误解剖。

镜头图优先在正确画幅生成，16:9的2048×1152可作为所需目标之一，具体服从用途与工具返回。内置入口未提供size/quality参数时只描述画幅与清晰目标，返图后核实，不能编出参数或承诺原生4K。更高型号也不证明每幅图一定更好。

收到非目标画幅先评估裁切是否损害脸、手、道具与空间，必要时用内置编辑补画或重新构图，并复核身份与透视；不能拉伸人物或默认加黑边。初尾状态的画幅和轴线一致。主体独立图的画幅不必与镜头图一致，普通参考也不自动锁视频比例。

人物拼图整体像素不等于每格脸部细节。裁出单格可能有利于主体识别，但不会增加已有信息；决定是否新生独立图要看实际细节与身份。不要机械把每幅图放大到4K当作返修。

传给视频服务的图必须就是已验收版本。保留原始母图，必要压缩另存副本并复核关键区域、画幅和文件身份；截图缩略图、聊天预览和过期URL不能冒充原件。本地内置图不是公网URL，按已授权视频平台的上传/内联方式验证读取；缺渠道记录缺口，不另付费重生图只为拿链接。

## 五种按需提示骨架

按任务取所需字段，生成正文不用秒数时间轴。模板不绑定某片演员或配乐。

### 独立身份

```text
用途：视频人物独立身份参考。
输入：最新认可原图中的同一个人；原图多视角属于同一个人。
画面：一位人物，一幅正面头肩照，头发和下颌完整，平视，自然表情。
光线与质感：干净中性背景，柔和均匀光，自然肤质，眼睛与五官清楚。
保留：原身份、脸型与五官比例、发际线、发型及已指定配饰。
变化：仅调整为指定的独立视角与构图，不重新设计相似的新人物。
```

### 场次定妆

```text
用途：当前场次服装与身体比例参考。
图1控制人物身份；图2只控制指定服装。
同一人独立全身或所需半身，平视，自然站姿，衣服轮廓和关键配饰完整。
保留脸与发型；仅更换本次指定服装、姿态与拍摄距离。
衣料褶皱、手部和光影自然，不新增配饰。
```

### 场景与布局

```text
用途：当前镜头的空间基准。
明确地点、目标画幅、景别、摄影机所在侧与高度、门窗/桌椅/通道的位置。
主光来自指定实际光源，前中后景可读，保留必要移动空间。
仅控制场景时不加入陌生角色；布局参考只借站位/视线，不复制画风与标注。
```

### 镜头初态

```text
用途：镜头开始时的一幅单幅画面，保持本项目已选的写实或动漫画风。
逐图指定人物身份、服装、场景和布局用途。
逐人说明本镜已经在场者的位置、视线、姿势和手与道具的当前状态。
指定景别、机位、目标画幅、焦点与必要景深，关键脸/手/道具可读。
后续动作尚未完成；镜头终态另存，不提前加入待入场角色或待揭示设备。
保留认可身份、已确定衣服、空间与拍摄侧，不加入未要求元素。
```

### 局部修改

```text
以当前已选图为编辑底图，另以认可身份原图锚定人物。
先列保留项：正确的脸、发型、衣服、人数、站位、机位、画幅、光线和道具。
仅修改一个明确目标与区域，说明修改后可见状态及邻近物体的关系。
变化自然融入原光影与透视，原位置处理正确，不新增人物或物件副本。
```

## 进入视频前的验图与返修

先描述实际看见的画面，再与任务比较，避免只按提示词想象成功。检查整图、原尺寸关键区域及相邻镜头对照：

- 身份和连续性：同一人、服装/配饰、稳定特征、主角与配角区分；新增眼镜、美颜换脸或不对称特征镜像均具体记录。
- 人数和空间：总人数/本镜人数、唯一角色、站位、视线、比例、遮挡、动线与机位成立。
- 动作初态：手与道具归属、接触、杯具数量/材质、未提前完成后续动作或泄露结尾。
- 图像与传输：目标画幅、必要细节可辨、无明显错手/融合/多头/意外文字、实际上传的文件与选片一致。

记录“用途→实际偏差→本次只改什么→结果”。已通过项尽量保留。同错反复出现时回到身份源、改最近角度参考、拆场景或简化非核心条件，不无限原样重跑。用户已授权事项按范围执行，不逐图重复批准；核心身份/剧情/预算或工具路线改变才交用户决定。

静态合格后用关键镜头验证视频。需要对照参考方案时尽量固定视频通道、合法时长、文本、画幅与输出规格，比较身份、细节、动作和可用素材成本；一对随机样片不能证明普遍质量提升。技术尺寸检查、静态视觉审核、视频内容验收与用户艺术反馈分别记录。
