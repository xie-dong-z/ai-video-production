# 一份制作记录，贯通意图与素材

适用：跨镜角色/场景、多人互动、参考素材更新、长短片段组合、复拍或项目接手。只改一段提示词时可以直接使用已有素材和文字要求，不强制补齐全部表。已有项目记录可继续使用，只有要执行自动检查时才按下列可选JSON字段组织；不要重复维护两套对白、素材库或台账。

创作意图/素材用途放计划；接口能力与报价放项目provider配置；真实请求、回执、任务ID、终态和费用放任务台账。制作计划不替代提交记录，平台别名不等于原厂型号。

## 任务尝试与恢复

保存请求中的精确通道名与服务端返回的上游model，二者并列，不用返回的内部名字覆盖本次选型和价格。每次创建记录批准依据、创建序号、提交时间、请求/素材指纹和原始回执；资产稳定ID、提交序号及平台引用标签分别保留。减少或重排参考时同步改绑定。

创建次数、已接单数、完成数、实际消费和退款分别累计。修复传输没有取得任务ID也算一次创建尝试；有ID后的查询与下载不算新生成。暂停或旧失败状态保留历史，当前摘要按最新用户授权和本次状态更新，避免项目摘要与任务台账互相矛盾。

接单就保存ID与queued，完成后分别记录downloaded、技术检查、内容检查范围和用户反馈；不等下载完成才留下恢复入口。重启先读最新台账，对既有ID继续查询/下载，已有原片先核完整性，不再次生成。

## B：身份根与派生资产

原始认可身份为根；动漫化设计、定妆、侧面、镜头初态是分别复核的派生资产。新图每次与根比较，不把未经核准的漂亮新脸晋升成身份真相。角色与场景只补本镜需要的角度、衣服或状态，不默认整套批量。

稳定ID描述资产，文件版本/hash描述实际内容。记录 spec（身份/服装/风格/姿态等本资产要求）、文件 sha256、规范化 spec_hash、parents 的派生时指纹与 review 状态。review 明确区分 user_selected、agent_checked、pending；脚本没有视觉审片能力，不会替用户批准。

指纹基准在派生或验收时保存，不能每次检查前重写成当前值。原图、身份要求或风格更改后先复核受影响资产；子图文件没变也可能过期。过期不会自动删除，不牵连不相关分支。新版本另存，认可依据和旧版本保留。

`production_audit.py`输出当前文件/spec指纹和 stale；它不写回计划。将已复核的指纹作为基准，并在生成派生图时记录该次实际父指纹。远程URL未取回内容不能确认文件一致；有依赖但未记录派生指纹会报告证据缺口。

## C：节拍、导演镜头与生成单位

节拍是必须看到/听到的一项变化：提问、回答、沉默反应、递物、碰杯声等。按剧情顺序给稳定ID；对白记录 speaker、text 与画内/画外设计。一个长对白需要跨镜时，在计划中明确拆成子节拍；同一句回声或复述是另一个有理由的节拍。

shots 按顺序认领 beat_ids，clips 按顺序认领 shot_ids。一条生成可含多个导演镜头，最终可用长度另以真实选片记录。检查各节拍/镜头按计划恰好覆盖一次，防止台词漏掉、反应镜重复、镜头次序误改。多个生成候选属于同一 clip 的任务尝试/选片，不重复写成剧情发生两次。

从此记录编译当前模型正文：对白保持原文，画外说话仍需保留；参考用当前实际标签，声音与事件明确归属。正文不加时间轴。台词容量以实际声源或正常朗读估计，标注估计/实测；不全片硬套35字、4.5字每秒、2–5秒切镜等阈值。

## D：场景与道具状态

同一 scene_id 的空间基准保持门窗/桌椅、主光、轴线和人物关系。天气、时代或灯光变化写 variant_of 与变化原因。服装/姿态不混入永久身份定义，场景空镜不替代含人物的实际初态。

每个互动镜头记关键 start_state → event → end_state：杯在谁的哪只手、门开闭、物件位置、在场/画内人数、视线目标、动作是否已发生。相邻镜头比较必须连续的属性，改变需由剧情事件解释。例：杯在桌上 → 主角右手拿起 → 杯在右手；下一镜左手拿杯必须有换手事件或明确剪辑安排。

数字脚本只检查ID、覆盖与指纹；左右、接触、视线、情绪、动作连续性由实际画面审查。允许导演有意省略动作，但记录剪辑理由，不把漏拍改称艺术选择。

## 可执行最小示例

```json
{
  "project_id": "demo",
  "assets": [{
    "id": "motion-a", "kind": "video", "file": "motion.mp4",
    "spec": {"purpose": "走近后停步"}, "parents": [],
    "admission": "runtime", "allowed_use": ["motion", "camera"],
    "excluded_use": ["identity", "background", "music"], "review": "agent_checked"
  }],
  "beats": [
    {"id": "b1", "kind": "action", "text": "主角走近并停步"},
    {"id": "b2", "kind": "dialogue", "speaker": "主角", "text": "明天见。", "delivery": "onscreen"}
  ],
  "shots": [{"id": "s1", "beat_ids": ["b1", "b2"], "scene_id": "office"}],
  "clips": [{
    "id": "c1", "shot_ids": ["s1"],
    "prompt": "镜头1｜主角按已绑定参考视频的走近与停步动作，停稳后说：明天见。",
    "references": [{"asset_id": "motion-a", "role": "reference_video", "use": ["motion"]}]
  }]
}
```

示例须提供真实 motion.mp4 才能通过文件检查；不含视频模型/报价/预算，不可提交生成。预算预检时给clips补当前通道的model、seconds、resolution，并补budget_cny等原有字段。有 beats/shots 时对白从节拍派生；独立维护 dialogues 副本若不一致会报错。旧计划无新增字段仍按原格式检查。
