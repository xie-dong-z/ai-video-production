# 后期、声音与交付

## 素材与编辑决定

读取视频时长、尺寸、帧率、编码和音轨，抽帧并试听。记录实际动作与词尾；剧本时间不能代替真实音画。ASR的文字与说话者要复核，群喊、音乐和静默容易误识。

原片保留，工作副本/母版分开。记录片段顺序、入出点、硬切/过渡、跨镜对白、音乐来源和增益。只要求剪辑时不重生成合格镜头。

## 合成

按对白结束、动作落点和新信息切镜，减少重复起势与无信息停顿。跨地点/时代允许硬切。用户指定截断点不能因美观而放宽。

混合规格时统一必要尺寸、帧率、像素与声音格式。每个输入显式取v:0/a:0，每个输出显式映射；MP4轨道顺序可能不同。合法无声片段若最终需连续音轨，可补等长静音。

拼接前处理PTS和声画长度；按需要查当前FFmpeg concat、atrim、asetpts、aresample等文档。优先现有可用工具，不为普通剪辑下载重型模型。

## 声音分层

对白、环境、动作音效与配乐分别设计。正确原声优先；确需补配音/旁白时按角色和预算生成，依实际声音长度对齐。明显口型冲突先评估画面返修。

同一主角的旁白与对白应统一声音来源，尽量在同一次人声录制或生成中取得所需台词，再分句放入场景。若主角已选定声音，新增台词使用该音轨的短样作为音色参考；不能改用另一个声音后仅调音高并声称同一声线。按当前API核音频参考是否可传；接口存在不代表当前Key有可用TTS或克隆模型。参考生成、ASR和音高统计不证明声纹完全一致，实际听感仍须核听。


原片可能只有混合音轨，不承诺无损拆开。用户要求全程稳定低音量音乐时，用一条连续音乐层，不按镜头或对白断乐、放大或压低。先查源录音的实际静音和音量起伏；若用户要求听感均匀，先平衡音乐自身动态，再持续播放。明确要求精确固定增益时另遵循该约束，不把固定增益等同听感恒定。

混音用明确增益和映射；固定比例时注意amix的normalize，避免仅因层数变化改变音量。检查峰值和对白可懂度；某首录音的增益不当作通用数值。

音乐文件先确认可解码。受保护或非标准容器未成功读取时不宣称转换成功；正常播放录制等方案须已获授权，并核对实际录到范围。

## 字幕和验收

字幕按最终真实音轨对齐，不按剧本平均分时。实际视听检查错位、词尾、角色声音与用户语言/样式。

模型可能自行烧入对白字幕，甚至显示“画外”等提示描述，也可能把描述读成额外旁白。本次H3实测出现过；否定提示不构成成片保证。先检查字幕的真实位置，再决定安全裁切、统一画幅或返修，不能遮掉必要人物与道具；原声只保留经检查的对白窗口。字幕文本不证明发音正确，ASR也不能单独证明完整台词与口型一致。

多人入场适合用人数明确的不同状态参考和独立短片：例如一人、三人、五人、十人。每段仍逐帧核对走入、站位、身份和最终人数，不能把“参考图正确”当“视频正确”。照片定格后的摄影机揭示可以用实际合影参考做后期拉远；制作记录要注明这是照片与后期镜头，不冒充生成的视频运动。

media_audit.py检查完整解码、尺寸、帧率、时长、所需音轨与峰值。黑暗、静止、沉默结合剧情判断，不自动删。放大输出与原生高分辨率生成分别说明。

内容另审：人物/服装、人数/道具、动作先后、对白原文与发声者、口型、切点、音乐连续和情绪。没有看或听的项目标未验证。

交付可播放成片及需要的独立声轨/字幕，附版本、费用和检查结论。采用本次用途规格；对外发布或向他人发送另按明确授权。
