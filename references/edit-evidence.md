# E：源词、剪辑记录与审片证据

适用：对白剪辑、字幕、口播返修、成片内容定位。使用现有记录和工具，不要求固定ASR服务、GUI、云平台或每个切点确认。

## 原片时间和成片时间分开

对同一音轨版本缓存逐词转写，词ID指向 source_asset_id 与源入出时间；修改错字保留词ID与源时间，不能借纠错改写实际声音。不同音轨版本不能静默复用旧词时间。

edit.segments 按输出顺序保存 asset_id、源 in/out、speed。输出偏移从这份剪辑表计算，不另手填第二套时间。edit.words 保存稳定 id、asset_id、start/end、text；缓存转写时保存 source_sha256，锁定真实源文件版本。edit.captions 保存 id、word_ids、显示 text；相同源词被多次使用时指定 segment_id。

工具计算输出词时间 = 该片段输出起点 +（源词时间 − 源入点）/ speed。例：源2–6秒保留、speed=2，源3秒的词从该片段输出起点后0.5秒开始。不同片段字幕按切点拆分，不能一条字幕盖住已删除内容或跨跳切长时间停留。

```json
{
  "assets": [{"id": "take-a", "kind": "video", "file": "take-a.mp4", "duration_seconds": 8}],
  "edit": {
    "segments": [{"id": "e1", "asset_id": "take-a", "in": 2, "out": 6, "speed": 1}],
    "words": [{"id": "w1", "asset_id": "take-a", "start": 3, "end": 3.5, "text": "明天见"}],
    "captions": [{"id": "cap1", "word_ids": ["w1"], "text": "明天见。"}]
  }
}
```

检查结果字幕为成片1–1.5秒。时间来自记录，不是脚本测量音频得到。ASR帮助定位，不代替对实际声音、口型与字幕的复核。

默认不截断词，不自动删掉每个沉默/犹豫；它可能是表演与情绪。有用户明确要求的截词效果，在对应片段记录 allow_word_cut=true 与 word_cut_reason，再核实际截点。工具只检查例外已记录，不把填写原因当用户授权。音频变速、增益、淡入淡出与混音另记并实测；本脚本只映射恒速片段，不支持重叠转场、反向或变速曲线，遇到这些用编辑器实际时间线/渲染结果导出的映射，不能套公式冒充准确。

## 证据支撑返修

每次审片记录要求/节拍ID、原片或成片版本与hash、实际观察、定位帧或声音区间、偏差类别、修复办法、复核结果。稀疏filmstrip配合完整播放，波形帮助定位起止；波形不能识别对白内容或情绪。

身份/参考绑定/动作/空间/声音/字幕/剪辑分别定位根因。保存修改差异及旧版本，不重写用户核心意图来迁就失败片段。已验收片段按受影响依赖返修。结论区分：结构检查通过、技术检查通过、agent内容审片、用户认可；没有完整观看或音频理解时说明真实范围。
