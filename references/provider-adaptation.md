# 平台与API适配

## 换平台时保留与核对

当前平台迁移主要针对视频通道与素材传输。图片默认遵循主入口的GPT内置路线，不能因视频通道要公网URL而自动转图片API；先验证输出的正常上传或内联方式。当前项目最新明确选择其他GPT图片提供方时，单独核对型号别名、2K/4K字段、实际输出、计费与授权，不将平台公示能力当生成实测。

保留人物、摄影、分镜、预算、审片与后期规范。更新服务地址、认证、模型目录、各模式请求/返回映射、上传、状态与下载。只改模型名不算完成接入。

查当前官方文档和用户给的接口资料，分清原厂、代理、客户端本地来源与MCP。tauri.localhost可能是前端来源，不凭显示地址当外部HTTP服务。已有Key只发给授权提供方，不拿代理Key试其他原厂。

用户要求沿用旧方法时，先恢复成功请求、素材交付和查询下载记录，再核拟用精确别名的变化。既有REST链路可执行就直接复用；新的连接器或登录仅用于真实缺失的能力，不把额外账号连接变成上传图片的默认前置。图片托管和视频生成提供方分别记录。

## 项目适配记录

provider.json记录非秘密字段：provider_id、api_base、credential_env、models_endpoint、generation_mode、request_fields、task_id_field、task_status_field、success_states、failure_states、media_transport。

verification按catalog、upload、create、query、download_decode、billing、content逐项标pending/verified，并链接实际证据。未知字段保留pending，不能靠猜得到“通用适配器”。Key只在授权环境/安全凭据机制，不放配置、Skill或示例。

视频参考额外记录支持模式、数量/文件与总时长限制、字段和数组顺序、真实标签协议、附加输入计费与内容采用实测。规划资产ID与平台本次引用编号分别保存，按 [视频参考](video-references.md) 限定借用属性。账号Key日志、网页登录日志与管理员日志权限分开；任务ID、请求ID和展示日志序号各自保留，不能互换。

## 只读之后再验证生成

1. 核对服务、可见模型、公示报价；标准兼容目录可用refresh_models.py，不兼容提供方按正常接口读取。
2. 对拟用型号确认模式、时长、分辨率、数量/总时长、原生音频与附加费用。平台声明、原厂能力、客户端选项与真实成功分别记。
3. 本地文件不是云端URL。按支持的上传、公共URL或内联方式验证媒体可读，再核对身份/构图/边界角色，不擅自换收费托管。
4. 任务和预算明确后提交一条真实片段，保存提示词、素材hash、参数、ID、原状态、账单与结果。内容与技术通过后再批量。

## 参考素材交付

引用格式按提供方、精确模型别名和模式确认。HTTPS URL、data URI、上传后资产ID、本地文件各有适用入口，同家族或同为九图通道不证明可互换。公开资料与实际成功分开，明确拒绝过的格式不得再次套用。

使用公网URL时，选定素材上传后核对实际提交数组的顺序和提示绑定；先匿名GET取回可解码文件，检查内容类型、尺寸与指纹。只看HEAD、URL以https开头或本机能预览不足以证明上游可读取；blob与tauri本地地址不能作公网参考。链接有效期覆盖取图阶段，源链接到期与CDN缓存头分开记录，不保证缓存永久可读或按max-age删除。

托管或图像代理可能默认重新压缩、缩放和转换。需要保持图像时核最终返回文件；无损换编码比较解码像素与尺寸，有损压缩核关键细节并记录指标。不能凭raw参数、PNG扩展名或文件大小宣称保真。已有合格母图和上传副本保留，传输修复不需要付费重生角色。

## 根据实际错误定位

保留外层HTTP、原始回执、内层code/message和phase。REFERENCE_MEDIA_INVALID等通用文案不能独自判定图像质量或宽高比：connection reset、TLS失败或明确的网络timeout指向读取链路，解码、格式或尺寸的明确拒绝才支持对应修改。先修已定位的一类问题，再以实际接单和返片验证；不把取图故障改写成模型表演能力不足。

HTTP 524等网关超时且无任务ID时维持submission_unknown，只读核对本人日志或任务。日志可能延迟出现；未见消费不证明最终零费用。确认原提交已失败后，按剩余授权决定修正重试；创建POST不自动重发。

## 状态恢复与下载

保存项目、片段、尝试号、生成时型号、提示/素材hash、费用预估/预留、提交时间、任务ID与原始查询结果。旧素材不用当前下拉框归属。

可把供应商状态映射为queued/running/completed/failed/unknown，但保留原状态。接单不算完成。提交超时先查授权日志或任务；本地hash不证明服务端幂等。

真实ID和queued返回后持续查询；状态进度只是平台上报，不用百分比推算剩余时间。每次状态变化持久保存，重启从既有ID继续，不再创建。进度长期停留时可只读复查响应时间、缓存头或平台状态；下载失败只重试GET，保留已完成状态和原文件。

不要把Bearer凭据带到下载CDN或其他域；文档要求的授权同域下载端点才携带认证。未知重定向先核目标，不自动转发Key。

## 数据和通道调查

只读公开聚合或经授权的本人/组织统计。Key不自动给网页登录/管理员权限；401/403记录缺口，不伪造身份、提取Cookie或猜他人任务ID。

分开记录提交、终态、错误、退款、等待与内容可用。公开用量不是成功任务数；缺分母不能制造精确比较或置信区间。分组与统计接口不一致时并列保存，不混平均。

价格与能力快照带日期，调用前刷新。变化影响某通道时暂停该通道批量，其他已授权阶段继续。新平台重新验证，不把原厂能力直接赋给代理别名。
